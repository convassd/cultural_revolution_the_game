# Wen Ge Sha v0.1

[Play in your browser](https://convassd.github.io/cultural_revolution_the_game/)

This update improves the interface while retaining the v0.0 combat and balance rules.

- A compact desktop battlefield with player information beside each row and a separate, wider hand area.
- Matching 3:4 battlefield and hand cards, larger match text, and a fixed-width action panel.
- A match log that moves to the right when space permits and below the hand otherwise.
- Swipeable card rows on narrow screens and a portrait orientation hint.
- A home-screen rules guide that uses shared ability and relationship names, with distinct highlight colors.
- Updated Chinese titles, navigation labels and ability names.
- Investigation Materials now reveals enemy hand names directly in the middle hand strip; the next selection or game action restores the card backs.

Verification: 178 tests pass, along with TypeScript checking and the production build. Desktop and mobile viewport checks cover card proportions, control alignment, fixed action-panel width and hand reveal behavior.

GitHub Pages automatically deploys the latest verified build pushed to main.
