# Cultural Revolution: The Game v0.0.0

[Play in your browser](https://convassd.github.io/cultural_revolution_the_game/)

The first playable browser prototype, with a Simplified Chinese interface.

- 48 unique character cards and individual local SVG illustrations.
- Local two-player hot-seat and one-step greedy AI battles with random first/second seats.
- Resource growth, simultaneous combat, faction advantages and dynamic relationship-group bonuses.
- All eight reusable abilities and five unique character abilities.
- A filterable, sortable card gallery.
- Floating damage indicators, shattering death effects, and victory/defeat animation and sound.
- No backend, accounts, database or AI service calls.

Desktop browsers are the current focus. Balance is provisional; online multiplayer, saves, deck building and mobile adaptation are not included.

This release records the original prototype previously called v0.0. Its tag points to the original commit; historical source labels are preserved. GitHub Pages serves the latest verified build from the main branch.
